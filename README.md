## 💡 为什么用它

市面上大多数批量重命名工具都有这个问题：**一旦中途出错，文件就成了"半成品"，比不改还难收拾**。

`BatchRenamer` 把**数据安全**放在第一位：

- ✅ **两阶段重命名**——先把所有文件改成临时名，再改成最终名，从根本上避免"接力改名"时的覆盖冲突
- ✅ **失败自动回滚**——任一阶段出错，已改名的文件会自动恢复原状
- ✅ **冲突预检**——重命名前扫出所有重复目标名与覆盖现有文件的情况，禁止执行
- ✅ **目录变化检测**——预览后如果目录被外部程序改动，执行时会被拦下，要求重新预览
- ✅ **非法文件名校验**——Windows 保留字符、控制字符、超长文件名、系统保留名全部提前拦截

除此之外，它还提供：

- 🎯 **小数序号**——`1.1, 1.2, 1.3, ...` 或 `1.0, 1.05, 1.10, ...`，随你配置
- 🎯 **灵活排序**——按名称 / 修改时间 / 大小 / 类型，升序或降序
- 🎯 **扩展名过滤**——只处理 png、只处理 jpg，或组合过滤
- 🎯 **异步执行**——大目录不卡 UI，实时进度条，随时可取消
- 🎯 **12 套主题**——亮色暗色随意切换，界面持续在线

## ✨ 核心特性

### 🛡️ 数据安全

| 特性 | 说明 |
|---|---|
| **两阶段重命名** | 阶段 1：`原名 → 唯一临时名`；阶段 2：`临时名 → 目标名`。彻底解决"a→1, 1→2, b→3"式的接力冲突 |
| **自动回滚** | 任一阶段失败，逐文件探测当前位置并恢复原名；回滚失败的文件会**明确告知用户当前实际名称** |
| **冲突预检** | 预览时检测「目标名内部重复」和「目标名与现有文件重名」两类冲突，冲突存在时禁止执行 |
| **TOCTOU 检测** | 预览后目录若有新增 / 删除 / 修改，执行时被拦截，要求重新预览 |
| **预览签名** | 参数或文件列表变化时，预览自动失效 |
| **非法字符校验** | Windows 保留字符 `< > : " / \ | ? *`、控制字符、超长文件名、系统保留名（CON/PRN/COM1...）全部拦截 |

### 🎨 使用体验

- **实时参数提示**——小数序号位数不足时实时警告，一键应用建议值
- **进度条 + 取消**——处理过程可见、可取消，取消后同样自动回滚
- **自然排序**——`file2.png` 正确排在 `file10.png` 前
- **快捷键齐全**——Ctrl+O / F5 / Ctrl+R / Ctrl+Enter / F1 等 12 个快捷键
- **主题切换**——12 套亮/暗主题实时切换，无需重启
- **状态栏语义化**——灰色=待命、蓝色=信息、绿色=成功、黄色=提醒、红色=错误
